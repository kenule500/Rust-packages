# /sdrive:propose

Choose the base branch, create the feature branch, then write the specification, traceability, plan, and tasks

Run the SpecDrive command `/sdrive:propose`.

1. Read `.sdrive/commands/manifest.json` and find the entry for this command.
2. Read the agent file it names in `agentFile` (`.sdrive/agents/02-specification.md`).
3. Follow that agent's instructions exactly.
4. Run the validators the manifest lists for this command.
5. Stop at every human approval gate the agent defines.
