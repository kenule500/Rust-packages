# /sdrive:product-plan

Optionally create an approved product overview, conceptual app mockup, roadmap, milestones, and feature backlog

Run the SpecDrive command `/sdrive:product-plan`.

1. Read `.sdrive/commands/manifest.json` and find the entry for this command.
2. Read the agent file it names in `agentFile` (`.sdrive/agents/12-product-plan.md`).
3. Follow that agent's instructions exactly.
4. Run the validators the manifest lists for this command.
5. Stop at every human approval gate the agent defines.

Arguments: $ARGUMENTS
