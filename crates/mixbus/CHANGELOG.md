# Changelog

All notable changes to `mixbus` are documented here.

## 0.1.0 - unreleased

- Gain, constant-power pan, gate, compressor, sidechain ducker, and limiter.
- EBU R128-style K-weighting and gated integrated loudness.
- Off-thread plan build, block-boundary swap, and latency compensation.
- Lock-free master, per-bus, and per-source meters.
- Bounded control queue and finite-value sanitisation.
